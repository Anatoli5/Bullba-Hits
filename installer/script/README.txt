Bullba Hits {VERSION} - script installer for World of Tanks PC NA {CLIENT}. It copies the same files as the normal setup: the recorder .wotmod into mods\2.4.0.1 and the viewer into mods\configs\local.armor_inspector. No executable of ours runs - Install.cmd hands install.ps1 to Windows' own powershell.exe, so application control has no unsigned program of ours to judge.
To install: close the game, unpack this folder anywhere, double-click Install.cmd. The game folder C:\Games\World_of_Tanks_NA is taken by itself; for another path either run Install.cmd with the folder as the first argument ("Install.cmd D:\Games\World_of_Tanks_NA") or type the path when asked. Nothing is written until the client version, the realm, the closed game and every file of the package have been checked.
What it does not do: it makes no entry in Programs and Features, so it cannot be uninstalled from there, and it creates no desktop shortcut - open mods\configs\local.armor_inspector\Viewer.html in a browser. Battle records, extracted models and other mods are hashed before the copy and verified unchanged afterwards.
manifest.json lists every file of the payload with its SHA-256; files[] is the installer's own payload manifest as a list, and each path is both the destination under the game folder and the path inside payload\. A file marked onlyIfAbsent (the hangar panel mods, the empty history index) is left alone when the game folder already has one.
Backups: the previous build's viewer files go to mods\configs\local.armor_inspector\installer\backups\viewer-<date>-<time>\, an earlier recorder .wotmod to ...\installer\backups\<version>\ (a different file of the same version number to ...\<version>-<hash>\, never deleted), and the log of the run to ...\installer\script-install-<date>-<time>.log.
